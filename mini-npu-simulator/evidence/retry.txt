=== Mini NPU Simulator ===
1. 사용자 입력 (3x3)
2. data.json 분석
선택: 
필터 A (3행, 각 행 3개 숫자, 공백 구분)
1행: 입력 오류: 열 개수가 맞지 않습니다. 해당 행을 다시 입력하세요.
1행: 입력 오류: could not convert string to float: 'a'. 해당 행을 다시 입력하세요.
1행: 2행: 3행: 필터 A 저장 완료 (3x3)

필터 B (3행, 각 행 3개 숫자, 공백 구분)
1행: 2행: 3행: 필터 B 저장 완료 (3x3)

패턴 (3행, 각 행 3개 숫자, 공백 구분)
1행: 2행: 3행: 패턴 저장 완료 (3x3)
